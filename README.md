# LaTeX Resume Template

A one-page LaTeX resume template with ATS-readable PDF output. Replace the placeholder content in `resume.tex` with your own.

## Install LaTeX

Install a TeX distribution such as [MacTeX](https://www.tug.org/mactex/) or [TeX Live](https://www.tug.org/texlive/). Verify that `pdflatex` is on your `PATH`.

## Build

```bash
pdflatex resume.tex
```

The generated PDF and auxiliary files are ignored or checked in according to the repository configuration. The [LaTeX Workshop](https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop) VS Code extension provides live preview while editing.
